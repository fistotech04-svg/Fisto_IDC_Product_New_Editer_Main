# Backend Changes Tracking Rule

Whenever any modifications, additions, or removals are made to files in the `Backend/` directory (including routes, models, controllers, configs, middleware, server scripts, or assets):

1. **Update `Backend/backend_changes.md`**:
   - Add a new section or entry under the corresponding date.
   - Specify which files were modified and describe what changed (endpoints, database schemas, configuration, logic).
   - Keep the summary table at the bottom of the document up to date.
